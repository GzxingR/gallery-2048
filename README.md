# 2048 云上挑战

一个零依赖的单文件 2048 游戏，键盘与手势双操作，深色渐变界面，最高分本地持久化。

## 功能

- 方向键 / WASD 控制方块移动，支持移动端滑动手势
- 相同数字合并时带缩放动画，得分实时累加
- 最高分写入 localStorage，刷新页面不丢失
- 新游戏即时重开，无需刷新

## 技术实现

纯 HTML + CSS + JavaScript，无框架、无构建、无外部依赖。整个游戏压缩在一个 9.6 KB 的单文件里，双击即可运行，也可以直接丢到任意静态服务器上托管。

核心是经典的 4×4 网格合并算法：每次移动先按方向压缩非零方块，再对相邻同值方块合并并累加得分，最后补齐空位；若网格状态在移动前后完全一致，则判定该方向无效，不生成新方块。

## 部署方式

页面为纯静态资源，可直接部署到华为云 ECS：由 cloud-init 在实例初始化阶段写入站点目录，并用 systemd 托管的静态服务对外提供访问，实现开机自启与异常重启自愈。
